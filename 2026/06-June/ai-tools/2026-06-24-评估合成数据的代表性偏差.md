# 评估合成数据的代表性偏差

合成数据能扩充测试集，但可能重复模型固有偏差或遗漏真实用户的长尾情况。应保留真实样本基线，标注数据生成方式，并比较不同群体、语言和难度上的覆盖。不能仅因样本数量变大就认定评估更可靠。

## 落地步骤

1. 定义目标、影响范围和可观察的成功条件。
2. 明确输入边界、权限和失败时的恢复路径。
3. 在低风险环境先验证，保存版本和运行记录。
4. 评估回滚成本及未覆盖场景，避免只依据理想路径作结论。

## 示例

```python
def coverage_ratio(covered: int, total: int) -> float:
    return covered / total if total else 0.0
assert coverage_ratio(8, 10) == 0.8
```

## 验收清单

覆盖正常、边界和失败路径，检查日志不含秘密，并确认重复执行或并发不会造成意外结果。示例只展示核心机制，生产环境需要专项测试；未执行的测试不得宣称通过。
