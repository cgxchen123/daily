# 识别营销术语与可验证能力

技术宣传可能使用“自动化”“企业级”“实时”等宽泛术语。评估时要把这些词转成具体验收条件，例如延迟分位数、支持规模、故障恢复时间、权限模型和审计能力，并要求供应商提供可复现证据或试用验证。

## 落地步骤

1. 定义目标、影响范围和可观察的成功条件。
2. 明确输入边界、权限和失败时的恢复路径。
3. 在低风险环境先验证，保存版本和运行记录。
4. 评估回滚成本及未覆盖场景，避免只依据理想路径作结论。

## 示例

```python
def has_measurable_acceptance(metric: str, threshold: str) -> bool:
    return bool(metric.strip() and threshold.strip())
assert has_measurable_acceptance('p95 latency', '< 200ms')
```

## 验收清单

覆盖正常、边界和失败路径，检查日志不含秘密，并确认重复执行或并发不会造成意外结果。示例只展示核心机制，生产环境需要专项测试；未执行的测试不得宣称通过。
