# 分析多模态模型的失败类型

多模态系统可能在文字、图像、语音和跨模态对应关系上出现不同错误。评估时应区分感知错误、指令遵循错误、幻觉和安全问题，并使用代表性输入覆盖模糊图像、遮挡、噪声和不同语言。单一总分难以说明风险。

## 实施建议

先明确目标、输入来源和成功条件。将校验、权限判断和副作用分离，确保拒绝路径没有留下部分状态。关键行为应有可复查的测试或审计记录，并在失败时给出清楚的恢复方式。

## 示例

```python
def classify_issue(kind: str) -> str:
    allowed = {'perception', 'hallucination', 'instruction', 'safety'}
    return kind if kind in allowed else 'other'
assert classify_issue('perception') == 'perception'
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认日志不含秘密、资源有上限、重复操作不会造成意外副作用。示例仅展示核心机制，生产环境需要专项测试。未实际运行的测试不得宣称通过。
