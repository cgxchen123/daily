# 避免可变默认参数导致状态泄漏

函数默认参数只在函数定义时求值。如果默认值是列表或字典，多次调用可能共享同一个对象，导致数据意外累积。使用 None 或明确的工厂函数创建每次调用独立的容器，并为重复调用编写测试。

## 实施建议

先明确目标、输入来源和成功条件。将校验、权限判断和副作用分离，确保拒绝路径没有留下部分状态。关键行为应有可复查的测试或审计记录，并在失败时给出清楚的恢复方式。

## 示例

```python
def add_label(label: str, labels=None):
    if labels is None:
        labels = []
    labels.append(label)
    return labels
assert add_label('a') == ['a']
assert add_label('b') == ['b']
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认日志不含秘密、资源有上限、重复操作不会造成意外副作用。示例仅展示核心机制，生产环境需要专项测试。未实际运行的测试不得宣称通过。
