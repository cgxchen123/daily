# 用 tempfile 写可靠的文件测试

测试真实文件操作时，固定临时文件名容易与并发测试冲突或遗留脏数据。tempfile 能创建隔离目录或文件，并在退出后清理。测试还应覆盖权限错误、编码问题和文件不存在等场景。

## 实施方法

先定义成功条件和失败时的行为，把事实、假设与待验证问题分开记录。对关键操作明确权限、输入边界和恢复方式，并为验证结果保留版本、命令和可复查证据。涉及敏感信息时遵循最小化原则，不要把秘密复制到日志或示例。

## 示例

```python
from tempfile import TemporaryDirectory
from pathlib import Path
with TemporaryDirectory() as tmp:
    p = Path(tmp) / 'sample.txt'
    p.write_text('hello', encoding='utf-8')
    assert p.read_text(encoding='utf-8') == 'hello'
print('temporary file test passed')
```

## 验收清单

至少覆盖正常路径、边界路径和失败路径；说明示例未覆盖的限制。生产环境需根据真实并发、权限和依赖条件补充测试，未实际执行的测试不得宣称通过。
