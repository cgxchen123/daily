# 为备份文件设置访问控制

备份常常包含比在线系统更多的历史数据，若访问控制松散，可能成为高价值泄露源。应对备份加密、限制读取和恢复权限、隔离生产凭据，并定期演练恢复。备份存在不代表恢复可用，恢复测试需要验证数据完整性和业务一致性。

## 落地步骤

1. 定义目标、影响范围和可观察的成功条件。
2. 明确输入边界、权限和失败时的恢复路径。
3. 在低风险环境先验证，保存版本和运行记录。
4. 评估回滚成本及未覆盖场景，避免只依据理想路径作结论。

## 示例

```python
def can_restore(role: str) -> bool:
    return role in {'backup_admin', 'recovery_operator'}
assert can_restore('backup_admin')
assert not can_restore('viewer')
```

## 验收清单

覆盖正常、边界和失败路径，检查日志不含秘密，并确认重复执行或并发不会造成意外结果。示例只展示核心机制，生产环境需要专项测试；未执行的测试不得宣称通过。
