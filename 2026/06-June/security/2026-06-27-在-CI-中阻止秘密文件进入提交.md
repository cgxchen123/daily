# 在 CI 中阻止秘密文件进入提交

秘密扫描可以降低凭据被提交的概率，但工具需要结合文件类型、误报处理和例外审批。应优先阻止高置信度秘密进入主分支，并在发现泄露后立即轮换凭据。删除文件或让扫描通过并不能撤销已经公开的秘密。

## 实施步骤

1. 明确数据来源、目标范围和成功条件。
2. 在产生副作用前完成输入与权限检查。
3. 对失败、重试和恢复路径做独立验证。
4. 保存版本、命令和结果，避免把假设当作验证事实。

## 示例

```python
from pathlib import Path
root = Path('extract').resolve()
name = '../outside.txt'
target = (root / name).resolve()
if root not in target.parents:
    print('path traversal blocked')
```

## 验收与限制

至少覆盖正常路径、边界条件和失败路径。示例只展示核心机制，生产系统还需根据真实环境补充测试；未执行的测试不得宣称通过。
