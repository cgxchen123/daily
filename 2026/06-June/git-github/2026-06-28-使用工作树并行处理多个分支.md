# 使用工作树并行处理多个分支

git worktree 可以让多个分支在不同目录中同时检出，适合并行修复和审查。每个工作树有独立工作目录，但共享同一仓库对象数据库；创建和清理前要确认目录、分支和未提交修改，避免误删正在使用的工作区。

## 实施步骤

1. 明确数据来源、目标范围和成功条件。
2. 在产生副作用前完成输入与权限检查。
3. 对失败、重试和恢复路径做独立验证。
4. 保存版本、命令和结果，避免把假设当作验证事实。

## 示例

```bash
git status --short
git worktree list
# 创建工作树前确认目标分支未被另一个工作树检出。
```

## 验收与限制

至少覆盖正常路径、边界条件和失败路径。示例只展示核心机制，生产系统还需根据真实环境补充测试；未执行的测试不得宣称通过。
