# 为自动化流程增加心跳和告警

长任务没有日志并不一定代表故障，但没有心跳就很难区分空闲、卡死和进程退出。心跳应与实际进度关联，告警应考虑持续时间和误报；同时要确保告警接收渠道本身可用，并给出明确的排查入口。

## 落地步骤

1. 定义目标、影响范围和可观察的成功条件。
2. 明确输入边界、权限和失败时的恢复路径。
3. 在低风险环境先验证，保存版本和运行记录。
4. 评估回滚成本及未覆盖场景，避免只依据理想路径作结论。

## 示例

```python
def alert_needed(last_heartbeat: float, now: float, threshold: float) -> bool:
    return now - last_heartbeat > threshold
assert alert_needed(10, 30, 15)
```

## 验收清单

覆盖正常、边界和失败路径，检查日志不含秘密，并确认重复执行或并发不会造成意外结果。示例只展示核心机制，生产环境需要专项测试；未执行的测试不得宣称通过。
