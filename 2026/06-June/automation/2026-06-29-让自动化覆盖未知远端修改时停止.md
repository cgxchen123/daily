# 让自动化覆盖未知远端修改时停止

自动化发布前应读取远端当前版本，并确认变更基于预期状态。如果远端已被他人更新，应停止并重新评估，而不是强制覆盖。版本比较或 lease 能降低竞态风险，但失败后必须先回读状态再决定是否重试。

## 实施步骤

1. 明确数据来源、目标范围和成功条件。
2. 在产生副作用前完成输入与权限检查。
3. 对失败、重试和恢复路径做独立验证。
4. 保存版本、命令和结果，避免把假设当作验证事实。

## 示例

```python
def may_retry(error_kind: str, attempt: int, limit: int) -> bool:
    return error_kind in {'timeout', 'temporary_network'} and attempt < limit
assert may_retry('timeout', 1, 3)
assert not may_retry('invalid_input', 1, 3)
```

## 验收与限制

至少覆盖正常路径、边界条件和失败路径。示例只展示核心机制，生产系统还需根据真实环境补充测试；未执行的测试不得宣称通过。
