# 评估双许可证的适用条件

双许可证项目可能允许使用者在不同许可条件之间选择，但选择权、版本范围和例外条款需要逐一核对。不要只看仓库徽章或包页面标签，应检查具体版本的许可证文本，并在商业分发或专利问题不明确时寻求专业意见。

## 落地步骤

1. 定义目标、影响范围和可观察的成功条件。
2. 明确输入边界、权限和失败时的恢复路径。
3. 在低风险环境先验证，保存版本和运行记录。
4. 评估回滚成本及未覆盖场景，避免只依据理想路径作结论。

## 示例

```python
from dataclasses import dataclass
@dataclass(frozen=True)
class LicenseChoice:
    version: str
    license_text_reviewed: bool
assert LicenseChoice('v1', True).license_text_reviewed
```

## 验收清单

覆盖正常、边界和失败路径，检查日志不含秘密，并确认重复执行或并发不会造成意外结果。示例只展示核心机制，生产环境需要专项测试；未执行的测试不得宣称通过。
