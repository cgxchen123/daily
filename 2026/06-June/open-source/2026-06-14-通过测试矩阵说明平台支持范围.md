# 通过测试矩阵说明平台支持范围

项目的支持范围应通过测试矩阵明确展示 Python 版本、操作系统、架构和关键依赖组合。只在开发者电脑上成功并不能证明所有组合可用；对于不再测试的平台，应说明其支持状态，避免用户误以为得到保证。

## 实施建议

先明确目标、输入来源和成功条件。将校验、权限判断和副作用分离，确保拒绝路径没有留下部分状态。关键行为应有可复查的测试或审计记录，并在失败时给出清楚的恢复方式。

## 示例

```python
from dataclasses import dataclass
@dataclass(frozen=True)
class Support:
    python_version: str
    platform: str
    tested: bool
assert Support('3.12', 'linux', True).tested
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认日志不含秘密、资源有上限、重复操作不会造成意外副作用。示例仅展示核心机制，生产环境需要专项测试。未实际运行的测试不得宣称通过。
