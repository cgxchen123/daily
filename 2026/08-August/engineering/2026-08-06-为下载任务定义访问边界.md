# 为下载任务定义访问边界

下载任务应明确调用者、目标对象和允许的操作范围。不可猜测的链接只能降低偶然发现概率，不能替代授权。对重要文件应设置访问期限、记录访问事件，并避免在错误信息中暴露服务器内部路径。

## 实施步骤

1. 定义可观察的成功条件和失败状态。
2. 在产生副作用前完成输入与状态校验。
3. 记录版本、运行条件和验证证据。
4. 对不可逆操作准备备份、审批或恢复方式。

    return value
