# 为数据修复脚本先做只读演练

数据修复脚本可能造成不可逆影响。先实现只读模式，输出将匹配的记录数和变更摘要，再在备份和审批到位后执行写入。脚本应具备重复执行保护、分批处理和中断恢复能力。

## 实施步骤

1. 定义可观察的成功条件和失败状态。
2. 在产生副作用前完成输入与状态校验。
3. 记录版本、运行条件和验证证据。
4. 对不可逆操作准备备份、审批或恢复方式。

## 示例

```python
def ready(value: bool) -> bool:
    return value
assert ready(True)
print('check passed')
```

## 验收与限制

覆盖正常路径、边界条件和失败路径；说明尚未验证的部分。示例仅展示核心机制，生产环境需要专项测试。未实际运行的测试不得宣称通过。
