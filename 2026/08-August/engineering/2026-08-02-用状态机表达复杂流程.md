# 用状态机表达复杂流程

多阶段流程若依赖多个布尔值记录状态，容易出现相互矛盾的组合。状态机将允许的状态和转换显式化，并为每次转换定义条件、副作用和失败处理。对持久化任务，还应确保中断后能够从已确认状态恢复。

## 实施步骤

1. 定义可观察的成功条件和失败状态。
2. 在产生副作用前完成输入与状态校验。
3. 记录版本、运行条件和验证证据。
4. 对不可逆操作准备备份、审批或恢复方式。

## 示例

```python
def ready(value: bool) -> bool:
    return value
assert ready(True)
print('check passed')
```

## 验收与限制

覆盖正常路径、边界条件和失败路径；说明尚未验证的部分。示例仅展示核心机制，生产环境需要专项测试。未实际运行的测试不得宣称通过。
