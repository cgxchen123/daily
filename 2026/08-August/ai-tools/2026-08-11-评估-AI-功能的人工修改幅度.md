# 评估 AI 功能的人工修改幅度

用户频繁大幅修改模型输出，可能说明生成结果不贴合真实任务。除了满意度，还可统计编辑距离、删除和新增比例、采纳率及完成时间，并按任务类型分析。指标需要配合人工抽样，避免误读。

## 实施步骤

1. 定义可观察的成功条件和失败状态。
2. 在产生副作用前完成输入与状态校验。
3. 记录版本、运行条件和验证证据。
4. 对不可逆操作准备备份、审批或恢复方式。

## 示例

```python
def ready(value: bool) -> bool:
    return value
assert ready(True)
print('check passed')
```

## 验收与限制

覆盖正常路径、边界条件和失败路径；说明尚未验证的部分。示例仅展示核心机制，生产环境需要专项测试。未实际运行的测试不得宣称通过。
