# 建立可复现的模型评测报告

评测报告应记录模型标识、提示词版本、参数、数据集、检索索引、评分标准和运行时间。没有这些信息，分数变化很难归因。报告还应包含失败案例和未覆盖范围，不能只展示平均分或挑选成功输出。

## 实施流程

1. 定义输入、输出和可观察的成功条件。
2. 明确失败时的停止、重试或恢复方式。
3. 在低风险环境验证，再记录实际运行结果。
4. 将版本、依赖和未覆盖范围写入交付记录。

## 示例

```python
def retry_allowed(attempt: int, limit: int) -> bool:
    return attempt < limit
assert retry_allowed(1, 3)
assert not retry_allowed(3, 3)
```

## 验收与限制

至少覆盖正常、边界和失败路径；示例只说明核心机制，生产环境需要专项测试。未实际执行的测试不得宣称通过，涉及外部服务时还应记录其版本和实际行为。
