# 为模型输出设置事实来源约束

模型生成的流畅文本不一定有可靠依据。需要事实支撑的回答应明确可用来源、要求关键结论与证据关联，并在来源不足时允许拒答。评估时应检查引用是否真实支持结论，而不是只验证是否出现了链接。

## 实施步骤

1. 定义可观察的成功条件和失败状态。
2. 在产生副作用前完成输入与状态校验。
3. 记录版本、运行条件和验证证据。
4. 对不可逆操作准备备份、审批或恢复方式。

## 示例

```python
def ready(value: bool) -> bool:
    return value
assert ready(True)
print('check passed')
```

## 验收与限制

覆盖正常路径、边界条件和失败路径；说明尚未验证的部分。示例仅展示核心机制，生产环境需要专项测试。未实际运行的测试不得宣称通过。
