# 评估技术采用后的退出成本

技术选型不只决定如何开始，也决定将来如何迁移。评估时应检查数据导出、开放格式、替代工具、许可限制、人员技能和停机窗口；把退出方案写入试点验收，可以减少未来被单一供应商锁定的风险。

## 实施步骤

1. 定义可观察的成功条件和失败状态。
2. 在产生副作用前完成输入与状态校验。
3. 记录版本、运行条件和验证证据。
4. 对不可逆操作准备备份、审批或恢复方式。

## 示例

```python
def ready(value: bool) -> bool:
    return value
assert ready(True)
print('check passed')
```

## 验收与限制

覆盖正常路径、边界条件和失败路径；说明尚未验证的部分。示例仅展示核心机制，生产环境需要专项测试。未实际运行的测试不得宣称通过。
