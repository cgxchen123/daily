# 对失败重试设置总时限

即使每次请求都有超时，连续重试仍可能让整个任务拖得过久。应同时设置单次超时、最大尝试次数和总时限，并在预算耗尽时停止后续动作。重试前应确认上一次操作是否已经生效。

## 实施步骤

1. 定义可观察的成功条件和失败状态。
2. 在产生副作用前完成输入与状态校验。
3. 记录版本、运行条件和验证证据。
4. 对不可逆操作准备备份、审批或恢复方式。

## 示例

```python
def ready(value: bool) -> bool:
    return value
assert ready(True)
print('check passed')
```

## 验收与限制

覆盖正常路径、边界条件和失败路径；说明尚未验证的部分。示例仅展示核心机制，生产环境需要专项测试。未实际运行的测试不得宣称通过。
