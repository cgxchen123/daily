# 为任务增加运行时长监控

任务时长逐渐增加可能预示输入增长、依赖变慢或性能回归。应记录开始和结束时间、阶段耗时、输入规模与结果状态，并用基线或分位数识别异常。监控应能区分正常的批次变化与真正的卡顿。

## 实施流程

1. 定义输入、输出和可观察的成功条件。
2. 明确失败时的停止、重试或恢复方式。
3. 在低风险环境验证，再记录实际运行结果。
4. 将版本、依赖和未覆盖范围写入交付记录。

## 示例

```python
def duration_seconds(start: float, end: float) -> float:
    if end < start: raise ValueError('end precedes start')
    return end - start
assert duration_seconds(1, 4) == 3
```

## 验收与限制

至少覆盖正常、边界和失败路径；示例只说明核心机制，生产环境需要专项测试。未实际执行的测试不得宣称通过，涉及外部服务时还应记录其版本和实际行为。
