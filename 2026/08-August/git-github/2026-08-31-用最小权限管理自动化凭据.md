# 用最小权限管理自动化凭据

自动化账户只应获得完成任务所需的仓库和操作权限。应优先采用短期凭据，限制访问范围，定期检查授权，并验证凭据撤销后任务确实停止访问。权限不足时应失败并报告，不要自动升级权限绕过限制。

## 实施流程

1. 明确输入来源、目标范围和成功条件。
2. 将检查与实际变更分开，避免验证失败后留下半成品。
3. 记录版本、命令、结果和未覆盖范围。
4. 对重要操作准备恢复方案并在低风险环境演练。

## 示例

```bash
git status --short
# 在 CI 中使用最小权限凭据，并验证授权范围。
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认结果可以复核。示例仅展示核心机制，生产环境需专项测试，未实际执行的测试不得宣称通过。
