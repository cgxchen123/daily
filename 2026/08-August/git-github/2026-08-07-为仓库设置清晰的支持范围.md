# 为仓库设置清晰的支持范围

仓库应明确支持的运行时版本、操作系统、依赖和不支持的用法。声明要与自动化测试矩阵保持一致；未验证的平台应标注为未测试，而不是暗示兼容。支持范围变更时，应在发布说明中同步记录。

## 实施步骤

1. 定义可观察的成功条件和失败状态。
2. 在产生副作用前完成输入与状态校验。
3. 记录版本、运行条件和验证证据。
4. 对不可逆操作准备备份、审批或恢复方式。

## 示例

```python
def ready(value: bool) -> bool:
    return value
assert ready(True)
print('check passed')
```

## 验收与限制

覆盖正常路径、边界条件和失败路径；说明尚未验证的部分。示例仅展示核心机制，生产环境需要专项测试。未实际运行的测试不得宣称通过。
