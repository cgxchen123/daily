# 为日志增加关联 ID

当多个请求并发处理时，仅靠时间戳很难把相关日志串起来。为每个请求或任务分配关联 ID，并在下游调用中传递，能提高排查效率。关联 ID 不应包含个人信息，外部传入的 ID 也应限制长度和格式。

## 实施步骤

1. 定义可观察的成功条件和失败状态。
2. 在产生副作用前完成输入与状态校验。
3. 记录版本、运行条件和验证证据。
4. 对不可逆操作准备备份、审批或恢复方式。

## 示例

```python
import uuid
request_id = str(uuid.uuid4())
assert len(request_id) == 36
print('request_id=', request_id)
```
