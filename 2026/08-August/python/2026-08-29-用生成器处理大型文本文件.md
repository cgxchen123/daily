# 用生成器处理大型文本文件

一次性读取大型文件会让内存随输入规模增长。生成器可以逐条产出记录，保持有界内存；如果后续步骤需要重复遍历或随机访问，则应明确选择缓存或分块索引。

## 实施流程

1. 明确输入来源、目标范围和成功条件。
2. 将检查与实际变更分开，避免验证失败后留下半成品。
3. 记录版本、命令、结果和未覆盖范围。
4. 对重要操作准备恢复方案并在低风险环境演练。

## 示例

```python
from pathlib import Path
def lines(path: Path):
    with path.open(encoding='utf-8') as f:
        for line in f:
            yield line.rstrip('\n')
print('use lines(Path("input.txt")) to stream a file')
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认结果可以复核。示例仅展示核心机制，生产环境需专项测试，未实际执行的测试不得宣称通过。
