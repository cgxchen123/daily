# 为模型输出保留人工停止开关

自动化模型流程应提供清晰的暂停和取消机制，尤其是在外部状态变化、证据不足或即将执行高影响动作时。停止后要保存当前阶段和已完成副作用，避免恢复时重复执行。停止机制必须由执行层实现，不能只依赖模型承诺停止。

## 实施步骤

1. 明确成功条件、输入范围和失败状态。
2. 在执行前完成校验，并为高影响动作设置审批或停止机制。
3. 保存实际运行命令、版本、结果和未覆盖范围。
4. 发布后回读状态，确认产物和索引与预期一致。

## 示例

```python
def may_continue(cancel_requested: bool, approval_needed: bool, approved: bool) -> bool:
    return not cancel_requested and (not approval_needed or approved)
assert may_continue(False, False, False)
assert not may_continue(True, False, True)
```

## 验收清单

覆盖正常、边界和失败路径。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
