# 建立发布证据清单

发布完成应有可复查证据，而不只是一个成功提示。证据清单可以包括目标提交、制品校验值、测试命令与结果、配置版本、回滚点和发布后健康检查。每项应标注执行人、时间和限制；没有实际运行的测试必须明确写出。

## 实施步骤

1. 明确成功条件、输入范围和失败状态。
2. 在执行前完成校验，并为高影响动作设置审批或停止机制。
3. 保存实际运行命令、版本、结果和未覆盖范围。
4. 发布后回读状态，确认产物和索引与预期一致。

## 示例

```python
def release_ready(commit: str, tests_recorded: bool, rollback_known: bool) -> bool:
    return bool(commit) and tests_recorded and rollback_known
assert release_ready('abc123', True, True)
assert not release_ready('', True, True)
```

## 验收清单

覆盖正常、边界和失败路径。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
