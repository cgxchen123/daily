# 为流水线增加输入预检

预检应在产生副作用前验证必需文件、参数范围、权限和远端状态。它应快速、只读，并清楚记录每项检查结果，避免流程运行到一半才发现输入缺失。

## 实施步骤

1. 明确输入、输出和失败行为。
2. 把校验与副作用分开，减少部分成功状态。
3. 为边界条件与异常路径建立重复可执行的检查。
4. 记录实际验证环境、命令、结果和未覆盖限制。

## 示例

```python
def should_retry(kind: str) -> bool:
    return kind in {'timeout', 'temporary_network'}
assert should_retry('timeout')
assert not should_retry('invalid_input')
```

## 验收与限制

示例只展示核心机制，不等于完整生产实现。检查正常路径、边界条件和失败路径；涉及权限、并发或真实数据时应补充专项测试。未实际运行的测试不得宣称通过。
