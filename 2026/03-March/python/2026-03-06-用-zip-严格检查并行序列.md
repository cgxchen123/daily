# 用 zip 严格检查并行序列

zip 默认会在较短序列结束时停止，可能静默丢掉多余数据。若两组数据必须一一对应，可使用严格长度检查，或先显式验证长度。处理来自不同文件或接口的数据时，这种差异尤其容易造成错误映射。

## 实施建议

先定义要保护的状态、输入边界和失败时的行为。把验证与副作用分开，明确并发执行、重试和回滚的约束。涉及第三方组件时，记录具体版本、权限和运行条件，避免仅凭默认行为推断安全性或正确性。

## 示例

```python
left, right = [1, 2], ["a", "b"]
assert list(zip(left, right, strict=True)) == [(1, "a"), (2, "b")]
try:
    list(zip([1, 2], ["a"], strict=True))
except ValueError:
    print("length mismatch detected")
```

## 验收清单

覆盖正常输入、边界输入和失败路径；检查日志不含秘密，重复执行不会产生非预期副作用。示例仅展示核心机制，生产环境仍需结合实际框架、权限和并发模型验证。未实际运行的检查不得宣称通过。
