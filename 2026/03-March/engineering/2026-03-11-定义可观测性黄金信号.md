# 定义可观测性黄金信号

监控不应堆满无法采取行动的指标。延迟、流量、错误和饱和度可以作为服务健康的起点，但要根据业务补充关键交易成功率和依赖状态。每个告警都应有阈值依据、负责人和处置步骤。

## 实施方法

先明确要解决的问题、影响范围和失败时的处理方式。将可验证条件写成检查项，并把事实、假设和待验证内容分开记录。若依赖外部服务，应保留版本、请求时间和错误分类，但不要在日志中保存凭据或不必要的个人数据。

## 示例

```python
from queue import Queue, Full
q = Queue(maxsize=2)
q.put("one"); q.put("two")
try:
    q.put_nowait("three")
except Full:
    print("bounded queue rejected overflow")
```

## 验收清单

- 覆盖正常路径和至少一个失败路径。
- 确认重复执行或并发时不会产生意外结果。
- 记录实际运行环境、命令和结果。
- 说明示例未覆盖的生产限制，未执行的测试不得宣称通过。
