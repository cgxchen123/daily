# 用背压保护下游服务

上游速度超过下游处理能力时，无限制并发会增加排队、内存和超时。可用有界队列、并发限制或速率控制传递拥塞信号，并明确满载时的处理策略。

## 实施步骤

1. 明确输入、输出和失败行为。
2. 把校验与副作用分开，减少部分成功状态。
3. 为边界条件与异常路径建立重复可执行的检查。
4. 记录实际验证环境、命令、结果和未覆盖限制。

## 示例

```python
from queue import Queue, Full
q = Queue(maxsize=1)
q.put('first')
try:
    q.put_nowait('second')
except Full:
    print('queue full; backpressure applied')
```

## 验收与限制

示例只展示核心机制，不等于完整生产实现。检查正常路径、边界条件和失败路径；涉及权限、并发或真实数据时应补充专项测试。未实际运行的测试不得宣称通过。
