# 设计有界队列避免内存无限增长

如果生产速度持续高于消费速度，无界队列会让内存不断增长，最终造成进程崩溃。队列应有容量上限，并明确满载时的行为，例如阻塞、拒绝、丢弃低优先级任务或施加背压；不同策略需要与业务丢失容忍度匹配。

## 实施方法

先明确要解决的问题、影响范围和失败时的处理方式。将可验证条件写成检查项，并把事实、假设和待验证内容分开记录。若依赖外部服务，应保留版本、请求时间和错误分类，但不要在日志中保存凭据或不必要的个人数据。

## 示例

```python
from queue import Queue, Full
q = Queue(maxsize=2)
q.put("a"); q.put("b")
try:
    q.put_nowait("c")
except Full:
    print("queue capacity reached")
```

## 验收清单

- 覆盖正常路径和至少一个失败路径。
- 确认重复执行或并发时不会产生意外结果。
- 记录实际运行环境、命令和结果。
- 说明示例未覆盖的生产限制，未执行的测试不得宣称通过。
