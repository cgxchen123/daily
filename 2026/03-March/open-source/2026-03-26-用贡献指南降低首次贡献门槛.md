# 用贡献指南降低首次贡献门槛

贡献指南应说明环境、测试命令、代码风格、提交要求和行为准则。示例与流程必须和仓库现状一致，不要写入项目实际没有执行的检查。

## 实施步骤

1. 明确输入、输出和失败行为。
2. 把校验与副作用分开，减少部分成功状态。
3. 为边界条件与异常路径建立重复可执行的检查。
4. 记录实际验证环境、命令、结果和未覆盖限制。

## 示例

```python
from dataclasses import dataclass
@dataclass(frozen=True)
class Review:
    version: str
    license_id: str
    evidence: str
assert Review('1.2.0', 'MIT', 'release license').version
```

## 验收与限制

示例只展示核心机制，不等于完整生产实现。检查正常路径、边界条件和失败路径；涉及权限、并发或真实数据时应补充专项测试。未实际运行的测试不得宣称通过。
