# 配置 Cookie 的安全属性

会话 Cookie 应根据应用场景设置 Secure、HttpOnly 和 SameSite 等属性。它们分别帮助限制明文传输、脚本读取和部分跨站请求风险，但不能替代 CSRF 防护、会话过期和服务器端授权。部署时还应确认 HTTPS 与反向代理配置正确。

## 实施建议

先定义要保护的状态、输入边界和失败时的行为。把验证与副作用分开，明确并发执行、重试和回滚的约束。涉及第三方组件时，记录具体版本、权限和运行条件，避免仅凭默认行为推断安全性或正确性。

## 示例

```python
cookie = {"secure": True, "httponly": True, "samesite": "Lax", "path": "/"}
assert cookie["secure"] and cookie["httponly"]
print("cookie policy reviewed")
```

## 验收清单

覆盖正常输入、边界输入和失败路径；检查日志不含秘密，重复执行不会产生非预期副作用。示例仅展示核心机制，生产环境仍需结合实际框架、权限和并发模型验证。未实际运行的检查不得宣称通过。
