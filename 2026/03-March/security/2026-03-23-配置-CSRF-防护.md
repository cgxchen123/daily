# 配置 CSRF 防护

浏览器自动携带会话 Cookie 时，恶意站点可能诱导非预期请求。CSRF 防护应结合随机令牌、SameSite Cookie 和来源检查，并匹配应用实际认证方式。

## 实施步骤

1. 明确输入、输出和失败行为。
2. 把校验与副作用分开，减少部分成功状态。
3. 为边界条件与异常路径建立重复可执行的检查。
4. 记录实际验证环境、命令、结果和未覆盖限制。

## 示例

```python
import hmac
def same(a: str, b: str) -> bool:
    return hmac.compare_digest(a, b)
assert same('token', 'token')
assert not same('token', 'other')
```

## 验收与限制

示例只展示核心机制，不等于完整生产实现。检查正常路径、边界条件和失败路径；涉及权限、并发或真实数据时应补充专项测试。未实际运行的测试不得宣称通过。
