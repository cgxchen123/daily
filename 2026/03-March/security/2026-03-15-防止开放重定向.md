# 防止开放重定向

如果应用接受任意跳转 URL，攻击者可能构造看似来自可信站点的链接，再把用户导向钓鱼页面。优先使用服务端定义的目标标识映射；若必须接受 URL，应解析并验证 scheme、host 和路径，不能只检查字符串前缀。

## 实施方法

先明确要解决的问题、影响范围和失败时的处理方式。将可验证条件写成检查项，并把事实、假设和待验证内容分开记录。若依赖外部服务，应保留版本、请求时间和错误分类，但不要在日志中保存凭据或不必要的个人数据。

## 示例

```python
from urllib.parse import urlparse

def safe_target(value: str) -> bool:
    parsed = urlparse(value)
    return parsed.scheme == "https" and parsed.hostname == "example.com"
assert safe_target("https://example.com/help")
assert not safe_target("https://example.com.attacker.test/")
```

## 验收清单

- 覆盖正常路径和至少一个失败路径。
- 确认重复执行或并发时不会产生意外结果。
- 记录实际运行环境、命令和结果。
- 说明示例未覆盖的生产限制，未执行的测试不得宣称通过。
