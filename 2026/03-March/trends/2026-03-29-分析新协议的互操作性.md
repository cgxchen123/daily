# 分析新协议的互操作性

协议设计先进不代表不同实现能正确协作。应检查正式规范、版本兼容、错误处理和实际互操作测试，优先验证目标设备与软件组合。

## 实施步骤

1. 明确输入、输出和失败行为。
2. 把校验与副作用分开，减少部分成功状态。
3. 为边界条件与异常路径建立重复可执行的检查。
4. 记录实际验证环境、命令、结果和未覆盖限制。

## 示例

```python
from dataclasses import dataclass
@dataclass(frozen=True)
class Check:
    version: str
    tested: bool
    limitation: str
item = Check('1.0', False, 'not yet tested')
print('verified' if item.tested else item.limitation)
```

## 验收与限制

示例只展示核心机制，不等于完整生产实现。检查正常路径、边界条件和失败路径；涉及权限、并发或真实数据时应补充专项测试。未实际运行的测试不得宣称通过。
