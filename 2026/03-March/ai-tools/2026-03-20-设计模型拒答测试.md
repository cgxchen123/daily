# 设计模型拒答测试

模型评测不能只包含它应该回答的问题，还要包含缺少依据、权限不足、涉及敏感操作和恶意提示等情况。拒答测试应判断模型是否识别边界、是否解释限制，以及是否泄露不应提供的信息；拒答率过高也可能损害正常任务效果。

## 实施方法

先明确要解决的问题、影响范围和失败时的处理方式。将可验证条件写成检查项，并把事实、假设和待验证内容分开记录。若依赖外部服务，应保留版本、请求时间和错误分类，但不要在日志中保存凭据或不必要的个人数据。

## 示例

```python
def should_escalate(has_evidence: bool, high_impact: bool) -> bool:
    return high_impact or not has_evidence
assert should_escalate(False, False)
assert should_escalate(True, True)
print("review policy checked")
```

## 验收清单

- 覆盖正常路径和至少一个失败路径。
- 确认重复执行或并发时不会产生意外结果。
- 记录实际运行环境、命令和结果。
- 说明示例未覆盖的生产限制，未执行的测试不得宣称通过。
