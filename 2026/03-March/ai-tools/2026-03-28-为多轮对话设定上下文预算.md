# 为多轮对话设定上下文预算

上下文窗口有限，长期堆积历史会增加成本并挤占当前任务信息。应定义保留规则，对摘要做事实核对，并保留关键原始证据的追溯路径。

## 实施步骤

1. 明确输入、输出和失败行为。
2. 把校验与副作用分开，减少部分成功状态。
3. 为边界条件与异常路径建立重复可执行的检查。
4. 记录实际验证环境、命令、结果和未覆盖限制。

## 示例

```python
def choose_context(messages: list[str], budget: int) -> list[str]:
    if budget < 0: raise ValueError('budget must be non-negative')
    return messages[-budget:] if budget else []
assert choose_context(['a','b','c'], 2) == ['b','c']
```

## 验收与限制

示例只展示核心机制，不等于完整生产实现。检查正常路径、边界条件和失败路径；涉及权限、并发或真实数据时应补充专项测试。未实际运行的测试不得宣称通过。
