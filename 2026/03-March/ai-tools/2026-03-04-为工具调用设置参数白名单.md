# 为工具调用设置参数白名单

工具调用即使来自模型，也应当被当作不可信输入。除工具名白名单外，还要校验参数类型、长度、允许的资源范围和用户权限；不能让模型通过自由文本决定任意文件路径、URL 或管理操作。

## 实施建议

先定义要保护的状态、输入边界和失败时的行为。把验证与副作用分开，明确并发执行、重试和回滚的约束。涉及第三方组件时，记录具体版本、权限和运行条件，避免仅凭默认行为推断安全性或正确性。

## 示例

```python
def validate_search_args(args: dict) -> str:
    q = args.get("query")
    if not isinstance(q, str) or not q.strip() or len(q) > 200:
        raise ValueError("invalid query")
    return q.strip()
assert validate_search_args({"query":"docs"}) == "docs"
```

## 验收清单

覆盖正常输入、边界输入和失败路径；检查日志不含秘密，重复执行不会产生非预期副作用。示例仅展示核心机制，生产环境仍需结合实际框架、权限和并发模型验证。未实际运行的检查不得宣称通过。
