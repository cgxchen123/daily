# 为模型回答建立引用核验步骤

引用核验要确认来源确实存在、可访问，并且内容支持对应结论。模型可能生成看似合理但不存在的引用，因此应在展示前独立检索和验证。无法核验时应降低断言强度或明确说明没有足够证据。

## 实施步骤

1. 明确目标、输入边界和成功条件。
2. 在产生副作用前完成校验，并区分失败类型。
3. 保存版本、命令、结果和未覆盖范围。
4. 对发布或数据变更准备恢复方案，并在低风险环境验证。

## 示例

```python
def citation_verified(source_exists: bool, supports_claim: bool) -> bool:
    return source_exists and supports_claim
assert citation_verified(True, True)
assert not citation_verified(True, False)
```

## 验收清单

覆盖正常、边界和失败路径，检查文档与真实文件一致。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
