# 记录模型提示词与索引版本

模型输出会受到提示词、模型版本、参数和检索索引影响。评测与线上记录应保存这些版本标识，才能解释质量变化并复现问题。记录时避免保存完整敏感输入，可使用脱敏样本或稳定摘要。

## 实施步骤

1. 明确成功条件、输入范围和失败状态。
2. 将检查与副作用分开，防止部分完成被误判为成功。
3. 为关键路径记录版本、实际命令和可复查结果。
4. 在目标环境补充边界、并发和恢复测试。

## 示例

```python
def factual_match(required: set[str], answer: set[str]) -> bool:
    return required <= answer
assert factual_match({'date','amount'}, {'date','amount','context'})
```

## 验收清单

覆盖正常路径、边界条件和失败路径。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
