# 为模型生成代码设置执行隔离

模型生成代码可能存在逻辑错误、资源消耗过大或不安全的系统访问。不要在拥有生产凭据的主进程中直接执行；应使用隔离环境、资源限制、文件系统边界和网络策略，并在执行前进行人工或自动审查。

## 实施流程

1. 明确输入来源、目标范围和成功条件。
2. 将检查与实际变更分开，避免验证失败后留下半成品。
3. 记录版本、命令、结果和未覆盖范围。
4. 对重要操作准备恢复方案并在低风险环境演练。

## 示例

```python
def may_run_generated_code(reviewed: bool, isolated: bool) -> bool:
    return reviewed and isolated
assert may_run_generated_code(True, True)
assert not may_run_generated_code(True, False)
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认结果可以复核。示例仅展示核心机制，生产环境需专项测试，未实际执行的测试不得宣称通过。
