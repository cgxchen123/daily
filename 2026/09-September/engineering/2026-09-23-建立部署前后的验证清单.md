# 建立部署前后的验证清单

部署前应检查制品版本、配置、迁移和回滚准备；部署后应验证健康状态、关键业务路径和错误率。清单要有明确通过标准和负责人，避免仅凭服务进程启动成功就认定发布完成。

## 实施步骤

1. 明确目标、输入边界和成功条件。
2. 在产生副作用前完成校验，并区分失败类型。
3. 保存版本、命令、结果和未覆盖范围。
4. 对发布或数据变更准备恢复方案，并在低风险环境验证。

## 示例

```python
def deployment_ready(artifact: bool, rollback: bool, checks: bool) -> bool:
    return artifact and rollback and checks
assert deployment_ready(True, True, True)
```

## 验收清单

覆盖正常、边界和失败路径，检查文档与真实文件一致。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
