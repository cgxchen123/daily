# 为关键路径设定资源预算

关键路径的 CPU、内存、线程和延迟应有预算。无限制重试、缓存或并发会让局部问题扩散为系统故障。应通过代表性负载建立基线，并在接近预算时触发限流、降级或告警。

## 实施步骤

1. 明确成功条件、输入范围和失败状态。
2. 将检查与副作用分开，防止部分完成被误判为成功。
3. 为关键路径记录版本、实际命令和可复查结果。
4. 在目标环境补充边界、并发和恢复测试。

## 示例

```python
def error_response(code: str, request_id: str) -> dict:
    return {'code': code, 'request_id': request_id}
assert error_response('NOT_FOUND', 'req-1')['code'] == 'NOT_FOUND'
```

## 验收清单

覆盖正常路径、边界条件和失败路径。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
