# 发布后回读验证远端结果

远端写入返回成功并不应是唯一验收依据。发布后应重新读取分支、文件和索引，确认内容存在、校验值匹配且链接有效。若远端状态与预期不同，应停止后续步骤并调查，而不是继续报告成功。

## 实施流程

1. 明确输入来源、目标范围和成功条件。
2. 将检查与实际变更分开，避免验证失败后留下半成品。
3. 记录版本、命令、结果和未覆盖范围。
4. 对重要操作准备恢复方案并在低风险环境演练。

## 示例

```python
def verified(remote_sha: str, expected_sha: str) -> bool:
    return bool(remote_sha) and remote_sha == expected_sha
assert verified('abc', 'abc')
assert not verified('abc', 'def')
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认结果可以复核。示例仅展示核心机制，生产环境需专项测试，未实际执行的测试不得宣称通过。
