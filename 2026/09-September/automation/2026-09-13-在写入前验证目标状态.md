# 在写入前验证目标状态

自动化任务不应假设目标文件或远端分支仍处于上次读取的状态。写入前应重新检查版本或使用条件更新；如果状态发生变化，应停止并重新计算计划，避免覆盖其他人的更新。

## 实施步骤

1. 明确成功条件、输入范围和失败状态。
2. 将检查与副作用分开，防止部分完成被误判为成功。
3. 为关键路径记录版本、实际命令和可复查结果。
4. 在目标环境补充边界、并发和恢复测试。

## 示例

```python
def state_matches(current: str, expected: str) -> bool:
    return bool(current) and current == expected
assert state_matches('v2', 'v2')
assert not state_matches('v3', 'v2')
```

## 验收清单

覆盖正常路径、边界条件和失败路径。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
