# 发布后验证索引和文档链接

文档发布后应检查新增文件是否存在、索引是否包含该文件，以及链接是否能解析到真实路径。索引更新与内容提交最好作为同一个原子提交；如果验证失败，应停止报告成功并修复缺失项。

## 实施步骤

1. 明确目标、输入边界和成功条件。
2. 在产生副作用前完成校验，并区分失败类型。
3. 保存版本、命令、结果和未覆盖范围。
4. 对发布或数据变更准备恢复方案，并在低风险环境验证。

## 示例

```python
from pathlib import Path
index = Path('INDEX_BY_DATE.md')
print('date index exists:', index.exists())
```

## 验收清单

覆盖正常、边界和失败路径，检查文档与真实文件一致。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
