# 评估多模型路由的实际收益

多模型路由可能根据任务难度、成本和延迟选择不同模型，但路由本身增加维护和评估复杂度。应先定义可测量的路由规则，与单模型基线比较整体质量、成本和失败率，并保留回退机制。

## 实施步骤

1. 明确目标、输入边界和成功条件。
2. 在产生副作用前完成校验，并区分失败类型。
3. 保存版本、命令、结果和未覆盖范围。
4. 对发布或数据变更准备恢复方案，并在低风险环境验证。

## 示例

```python
def worth_routing(quality_gain: float, extra_cost: float) -> bool:
    return quality_gain > extra_cost
assert worth_routing(0.2, 0.1)
```

## 验收清单

覆盖正常、边界和失败路径，检查文档与真实文件一致。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
