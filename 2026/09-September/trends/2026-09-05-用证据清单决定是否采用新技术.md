# 用证据清单决定是否采用新技术

技术选型应基于明确需求、可复现实验、维护能力、成本和退出路径。建立证据清单可以避免因演示效果或市场热度过早采用；对于尚未验证的能力，应列出验证负责人和截止时间。

## 实施流程

1. 明确输入来源、目标范围和成功条件。
2. 将检查与实际变更分开，避免验证失败后留下半成品。
3. 记录版本、命令、结果和未覆盖范围。
4. 对重要操作准备恢复方案并在低风险环境演练。

## 示例

```python
def evidence_ready(demand: bool, test: bool, exit_plan: bool) -> bool:
    return demand and test and exit_plan
assert evidence_ready(True, True, True)
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认结果可以复核。示例仅展示核心机制，生产环境需专项测试，未实际执行的测试不得宣称通过。
