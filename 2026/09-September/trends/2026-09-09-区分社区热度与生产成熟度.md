# 区分社区热度与生产成熟度

讨论量和关注度不能直接证明工具适合生产。还应检查维护节奏、升级策略、故障恢复、文档和安全响应能力。试点应验证团队能否自行部署、排错和迁移，而不是只复现官方演示。

## 实施步骤

1. 明确成功条件、输入范围和失败状态。
2. 将检查与副作用分开，防止部分完成被误判为成功。
3. 为关键路径记录版本、实际命令和可复查结果。
4. 在目标环境补充边界、并发和恢复测试。

## 示例

```python
def monthly_total(unit_cost: float, calls: int, ops: float) -> float:
    return unit_cost * calls + ops
assert monthly_total(0.01, 1000, 5) == 15
```

## 验收清单

覆盖正常路径、边界条件和失败路径。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
