# 为 CSV 导入验证表头

CSV 表头可能缺列、重复列或出现意外命名。导入前应验证必需字段、重复字段和字段数量，再处理行数据；对于大文件，逐行校验并报告行号可以降低内存消耗并方便修复。

## 实施流程

1. 明确输入来源、目标范围和成功条件。
2. 将检查与实际变更分开，避免验证失败后留下半成品。
3. 记录版本、命令、结果和未覆盖范围。
4. 对重要操作准备恢复方案并在低风险环境演练。

## 示例

```python
import csv
from io import StringIO
reader = csv.DictReader(StringIO('name,score\nAda,10\n'))
assert reader.fieldnames == ['name', 'score']
print(list(reader))
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认结果可以复核。示例仅展示核心机制，生产环境需专项测试，未实际执行的测试不得宣称通过。
