# 使用 pathlib 处理目录遍历

pathlib 能让路径拼接和规范化更清晰，但不自动保证路径安全。对不可信输入，应解析最终路径并确认其仍位于允许根目录；如果攻击者可以并发替换符号链接，还需要更严格的文件系统访问策略。

## 实施步骤

1. 明确成功条件、输入范围和失败状态。
2. 将检查与副作用分开，防止部分完成被误判为成功。
3. 为关键路径记录版本、实际命令和可复查结果。
4. 在目标环境补充边界、并发和恢复测试。

## 示例

```python
from pathlib import Path
root = Path('sandbox').resolve()
target = (root / 'reports' / 'out.txt').resolve()
if root not in target.parents:
    raise ValueError('path escapes root')
print(target)
```

## 验收清单

覆盖正常路径、边界条件和失败路径。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
