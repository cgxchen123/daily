# 对重要导出操作记录审计事件

审计事件应说明操作者、目标对象、动作、时间和结果。日志不应复制整个导出文件或敏感字段；需要追踪时可记录稳定对象 ID、请求 ID 和导出数量，并对日志访问和保留周期实施控制。

## 实施步骤

1. 明确成功条件、输入范围和失败状态。
2. 将检查与副作用分开，防止部分完成被误判为成功。
3. 为关键路径记录版本、实际命令和可复查结果。
4. 在目标环境补充边界、并发和恢复测试。

## 示例

```python
def audit_shape(actor: str, action: str, result: str) -> bool:
    return all(value.strip() for value in (actor, action, result))
assert audit_shape('user-1', 'export', 'success')
```

## 验收清单

覆盖正常路径、边界条件和失败路径。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
