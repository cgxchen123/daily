# 为公开下载内容设置缓存策略

公开资源与私密资源需要不同的缓存策略。敏感内容不应被共享缓存意外保存；可变资源应使用明确的 Cache-Control 和验证器。响应头应与身份验证、内容敏感度和更新频率一致，不能为了性能而忽略访问隔离。

## 实施步骤

1. 明确目标、输入边界和成功条件。
2. 在产生副作用前完成校验，并区分失败类型。
3. 保存版本、命令、结果和未覆盖范围。
4. 对发布或数据变更准备恢复方案，并在低风险环境验证。

## 示例

```python
def allowed_rows(count: int, maximum: int) -> bool:
    return 0 <= count <= maximum
assert allowed_rows(20, 100)
assert not allowed_rows(200, 100)
```

## 验收清单

覆盖正常、边界和失败路径，检查文档与真实文件一致。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
