# 为项目设置安全报告流程

安全报告流程应说明如何私下提交问题、预期响应方式和修复发布机制。公开讨论可能暴露可利用细节，因此要提供安全联系渠道；对外承诺的响应时限必须与维护能力相符。

## 实施流程

1. 明确输入来源、目标范围和成功条件。
2. 将检查与实际变更分开，避免验证失败后留下半成品。
3. 记录版本、命令、结果和未覆盖范围。
4. 对重要操作准备恢复方案并在低风险环境演练。

## 示例

```python
from dataclasses import dataclass
@dataclass(frozen=True)
class ReportRoute:
    channel: str
    response_expectation: str
assert ReportRoute('private email', 'acknowledge receipt').channel
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认结果可以复核。示例仅展示核心机制，生产环境需专项测试，未实际执行的测试不得宣称通过。
