# 为项目提供最小安装与测试命令

新用户应能从干净环境复现安装和基础测试。文档需要说明运行时版本、依赖安装、测试命令和预期结果；命令应与 CI 保持一致，避免 README 中的步骤逐渐过时。

## 实施步骤

1. 明确成功条件、输入范围和失败状态。
2. 将检查与副作用分开，防止部分完成被误判为成功。
3. 为关键路径记录版本、实际命令和可复查结果。
4. 在目标环境补充边界、并发和恢复测试。

## 示例

```python
from pathlib import Path
readme = Path('README.md')
print('README exists:', readme.exists())
```

## 验收清单

覆盖正常路径、边界条件和失败路径。示例仅展示核心机制，生产环境需要专项测试；未实际执行的测试不得宣称通过。
