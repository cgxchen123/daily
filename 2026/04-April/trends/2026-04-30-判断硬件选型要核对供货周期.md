# 判断硬件选型要核对供货周期

硬件评估除了性能和单价，还要核对供货周期、生命周期状态、替代型号、驱动支持和长期采购条件。原型阶段可以买到的模块，不代表量产或维护阶段仍然可得；关键器件应有替代计划和验证记录。

## 落地流程

1. 明确目标、输入来源和成功条件。
2. 识别异常、权限、并发与恢复边界。
3. 在低风险环境验证，再将结果纳入发布检查。
4. 记录实际版本、命令、结果与未覆盖范围。

## 示例

```python
def risk_score(severity: int, exposure: int, mitigation: int) -> int:
    return max(0, severity * exposure - mitigation)
assert risk_score(3, 4, 2) == 10
```

## 验收与限制

示例只说明核心机制，不能替代项目专项测试。至少覆盖正常、边界和失败路径；未实际执行的测试不得标记为通过。涉及生产数据或不可逆操作时，应先备份并确认回滚方案。
