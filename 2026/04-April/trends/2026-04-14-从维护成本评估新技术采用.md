# 从维护成本评估新技术采用

技术采用成本不只是开发时间，还包括培训、监控、升级、故障处理、迁移和退出成本。评估新技术时应明确现有痛点、可衡量收益和试验期限，并设定在收益不足时停止试验的条件。

## 推荐流程

先写明目的、输入来源、成功条件和失败时的动作。把可逆步骤与不可逆步骤分开，先在低风险环境验证；涉及外部依赖时，记录具体版本、权限和运行条件，避免根据默认行为推断安全性或可靠性。

## 示例与检查

```python
def net_value(benefit: float, adoption_cost: float, exit_cost: float) -> float:
    return benefit - adoption_cost - exit_cost
assert net_value(100, 30, 10) == 60
```

## 验收清单

覆盖正常路径、边界条件和失败路径；记录实际执行命令、输出和未覆盖限制。示例仅展示核心机制，不能替代项目专项测试。未实际执行的测试不得宣称通过。
