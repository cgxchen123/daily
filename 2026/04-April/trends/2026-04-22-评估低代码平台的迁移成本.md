# 评估低代码平台的迁移成本

低代码平台可以加快原型开发，但复杂逻辑、版本控制、测试、数据导出和供应商锁定可能影响长期维护。试用时要验证完整生命周期，包括故障排查、权限管理、自动化测试和退出平台时的数据迁移。

## 落地方法

先明确目标、输入来源和失败时的处理方式。把可验证条件写成检查项，分开记录事实、假设与待验证内容。涉及外部系统时应记录版本、时间和错误分类，避免保存凭据或不必要的个人数据。

## 示例

```python
def net_cost(build: float, operations: float, migration: float) -> float:
    return build + operations + migration
assert net_cost(10, 20, 5) == 35
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认重复执行不会造成意外副作用。示例只展示核心机制，不能替代项目专项测试。未实际执行的测试不得宣称通过。
