# 为 AI 功能建立非 AI 基线

如果没有简单规则、旧流程或人工流程作为对照，很难判断模型带来了多少实际收益。评估前应固定任务样本和成功标准，记录质量、耗时、成本与人工修改幅度，并避免用调参样本直接报告最终效果。

## 推荐流程

先写明目的、输入来源、成功条件和失败时的动作。把可逆步骤与不可逆步骤分开，先在低风险环境验证；涉及外部依赖时，记录具体版本、权限和运行条件，避免根据默认行为推断安全性或可靠性。

## 示例与检查

```python
def can_execute(high_impact: bool, approved: bool) -> bool:
    return not high_impact or approved
assert can_execute(False, False)
assert not can_execute(True, False)
assert can_execute(True, True)
```

## 验收清单

覆盖正常路径、边界条件和失败路径；记录实际执行命令、输出和未覆盖限制。示例仅展示核心机制，不能替代项目专项测试。未实际执行的测试不得宣称通过。
