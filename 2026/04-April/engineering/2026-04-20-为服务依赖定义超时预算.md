# 为服务依赖定义超时预算

服务链路中每个依赖都有延迟，若各自超时设置过长，整体请求可能超过用户等待上限。应从端到端预算反推各阶段时限，并考虑重试耗时；预算用尽后应尽快返回可恢复错误或执行降级。

## 落地方法

先明确目标、输入来源和失败时的处理方式。把可验证条件写成检查项，分开记录事实、假设与待验证内容。涉及外部系统时应记录版本、时间和错误分类，避免保存凭据或不必要的个人数据。

## 示例

```python
def remaining_budget(total: float, elapsed: float) -> float:
    return max(0.0, total - elapsed)
assert remaining_budget(2.0, 0.5) == 1.5
assert remaining_budget(2.0, 3.0) == 0.0
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认重复执行不会造成意外副作用。示例只展示核心机制，不能替代项目专项测试。未实际执行的测试不得宣称通过。
