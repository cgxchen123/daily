# 使用临时目录隔离任务产物

把中间文件写进固定共享目录，容易与其他运行冲突，也可能让失败产物被误当作正式结果。临时目录可以隔离每次执行的文件；任务结束后按成功或失败策略清理，并在需要排错时保存脱敏诊断包。

## 推荐流程

先写明目的、输入来源、成功条件和失败时的动作。把可逆步骤与不可逆步骤分开，先在低风险环境验证；涉及外部依赖时，记录具体版本、权限和运行条件，避免根据默认行为推断安全性或可靠性。

## 示例与检查

```python
from tempfile import TemporaryDirectory
from pathlib import Path
with TemporaryDirectory(prefix='task-') as tmp:
    result = Path(tmp) / 'result.txt'
    result.write_text('verified', encoding='utf-8')
    assert result.read_text(encoding='utf-8') == 'verified'
print('isolated artifact check passed')
```

## 验收清单

覆盖正常路径、边界条件和失败路径；记录实际执行命令、输出和未覆盖限制。示例仅展示核心机制，不能替代项目专项测试。未实际执行的测试不得宣称通过。
