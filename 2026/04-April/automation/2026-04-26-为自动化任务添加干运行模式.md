# 为自动化任务添加干运行模式

干运行模式应展示将要执行的动作，但不产生实际副作用。它有助于审查目标文件、资源范围和计划变更；不过，干运行与真实执行之间仍可能出现状态变化，因此真正执行前仍需重新校验远端或目标对象。

## 落地方法

先明确目标、输入来源和失败时的处理方式。把可验证条件写成检查项，分开记录事实、假设与待验证内容。涉及外部系统时应记录版本、时间和错误分类，避免保存凭据或不必要的个人数据。

## 示例

```python
def plan_publish(files: list[str], dry_run: bool) -> list[str]:
    return [f'WOULD PUBLISH {f}' if dry_run else f'PUBLISH {f}' for f in files]
assert plan_publish(['a.md'], True) == ['WOULD PUBLISH a.md']
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认重复执行不会造成意外副作用。示例只展示核心机制，不能替代项目专项测试。未实际执行的测试不得宣称通过。
