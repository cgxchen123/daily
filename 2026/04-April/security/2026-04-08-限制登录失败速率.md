# 限制登录失败速率

登录接口需要在安全性和可用性之间平衡。可以按账户、来源 IP 和整体系统设置分层限流，并监控异常分布；只按 IP 限流容易误伤共享网络，只按账户限流又可能被攻击者用来锁定他人账户。

## 推荐流程

先写明目的、输入来源、成功条件和失败时的动作。把可逆步骤与不可逆步骤分开，先在低风险环境验证；涉及外部依赖时，记录具体版本、权限和运行条件，避免根据默认行为推断安全性或可靠性。

## 示例与检查

```python
def within_limit(attempts: int, limit: int) -> bool:
    return 0 <= attempts < limit
assert within_limit(2, 5)
assert not within_limit(5, 5)
```

## 验收清单

覆盖正常路径、边界条件和失败路径；记录实际执行命令、输出和未覆盖限制。示例仅展示核心机制，不能替代项目专项测试。未实际执行的测试不得宣称通过。
