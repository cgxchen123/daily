# 为外部 URL 请求防护 SSRF

服务端代替用户访问 URL 时，攻击者可能诱导其请求内网地址、云元数据或本地服务。应限制协议和目标主机、解析并检查 IP、阻止重定向绕过，并在网络层实施出站访问控制。仅做字符串黑名单通常不够。

## 落地方法

先明确目标、输入来源和失败时的处理方式。把可验证条件写成检查项，分开记录事实、假设与待验证内容。涉及外部系统时应记录版本、时间和错误分类，避免保存凭据或不必要的个人数据。

## 示例

```python
from urllib.parse import urlparse
def allowed(url: str) -> bool:
    parsed = urlparse(url)
    return parsed.scheme == 'https' and parsed.hostname == 'docs.example.com'
assert allowed('https://docs.example.com/help')
assert not allowed('http://docs.example.com/')
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认重复执行不会造成意外副作用。示例只展示核心机制，不能替代项目专项测试。未实际执行的测试不得宣称通过。
