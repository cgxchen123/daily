# 生成软件物料清单的用途

SBOM 用于列出软件组件、版本和来源，帮助组织识别受影响依赖与许可证义务。它并不会自动证明软件安全；清单必须对应实际发布制品，并与漏洞情报、依赖锁文件和构建流程关联。

## 推荐流程

先写明目的、输入来源、成功条件和失败时的动作。把可逆步骤与不可逆步骤分开，先在低风险环境验证；涉及外部依赖时，记录具体版本、权限和运行条件，避免根据默认行为推断安全性或可靠性。

## 示例与检查

```python
from dataclasses import dataclass
@dataclass(frozen=True)
class Component:
    name: str
    version: str
    source: str
assert Component('lib', '1.0', 'registry').version
```

## 验收清单

覆盖正常路径、边界条件和失败路径；记录实际执行命令、输出和未覆盖限制。示例仅展示核心机制，不能替代项目专项测试。未实际执行的测试不得宣称通过。
