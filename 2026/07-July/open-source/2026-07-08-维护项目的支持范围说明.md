# 维护项目的支持范围说明

支持范围应明确 Python 或运行时版本、操作系统、架构、依赖版本和不支持的使用方式。声明要与 CI 测试矩阵一致；如果某个平台只是理论上可能工作但未验证，应明确标注未测试，而不是默认承诺支持。

## 实施步骤

1. 明确数据来源、目标范围和成功条件。
2. 在产生副作用前完成输入与权限检查。
3. 对失败、重试和恢复路径做独立验证。
4. 保存版本、命令和结果，避免把假设当作验证事实。

## 示例

```python
from dataclasses import dataclass
@dataclass(frozen=True)
class Support:
    runtime: str
    platform: str
    tested_in_ci: bool
assert Support('3.12', 'linux', True).tested_in_ci
```

## 验收与限制

至少覆盖正常路径、边界条件和失败路径。示例只展示核心机制，生产系统还需根据真实环境补充测试；未执行的测试不得宣称通过。
