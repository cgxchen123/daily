# 评估技术的退出与迁移路径

引入技术时就应考虑如何退出，包括数据导出格式、替代方案、许可证、迁移工作量和服务中断风险。无法迁移的锁定成本可能超过短期效率收益；应定期演练导出和恢复，而不是只在合同终止时处理。

## 实施方法

明确输入契约、权限边界和成功条件；把错误分类、恢复策略和审计记录一并设计。对外部依赖记录版本和真实行为，不能仅凭接口文档推断所有边界条件。重要操作应先在可恢复环境验证，并保留失败时的停止机制。

## 示例

```python
def readiness(docs: bool, releases: bool, support: bool) -> int:
    return sum((docs, releases, support))
assert readiness(True, True, False) == 2
```

## 验收清单

覆盖正常、边界和失败路径；确认没有秘密泄露，重复执行不会产生非预期副作用。示例仅展示核心机制，未在目标环境实际执行的测试不得宣称通过。
