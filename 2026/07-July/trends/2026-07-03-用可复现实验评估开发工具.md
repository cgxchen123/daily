# 用可复现实验评估开发工具

评估开发工具时应选取代表性任务，记录安装步骤、版本、硬件、耗时和失败情况。单次体验容易受缓存、熟练度和样本选择影响；重复运行并对照现有工具，才能判断收益是否稳定。

## 实施步骤

1. 明确数据来源、目标范围和成功条件。
2. 在产生副作用前完成输入与权限检查。
3. 对失败、重试和恢复路径做独立验证。
4. 保存版本、命令和结果，避免把假设当作验证事实。

## 示例

```python
def average_seconds(samples: list[float]) -> float:
    if not samples: raise ValueError('samples required')
    return sum(samples) / len(samples)
assert average_seconds([1.0, 3.0]) == 2.0
```

## 验收与限制

至少覆盖正常路径、边界条件和失败路径。示例只展示核心机制，生产系统还需根据真实环境补充测试；未执行的测试不得宣称通过。
