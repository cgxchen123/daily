# 限制正则表达式的输入长度

即使正则表达式本身看起来简单，某些模式遇到精心构造的长输入也可能消耗大量 CPU。对外部输入应设置长度上限，避免嵌套重复结构，并优先使用明确解析逻辑；安全测试需包含异常长字符串和最坏情况。

## 实施方法

明确输入契约、权限边界和成功条件；把错误分类、恢复策略和审计记录一并设计。对外部依赖记录版本和真实行为，不能仅凭接口文档推断所有边界条件。重要操作应先在可恢复环境验证，并保留失败时的停止机制。

## 示例

```python
def safe_length(value: str, maximum: int = 256) -> bool:
    return len(value) <= maximum
assert safe_length('short')
assert not safe_length('x' * 300)
```

## 验收清单

覆盖正常、边界和失败路径；确认没有秘密泄露，重复执行不会产生非预期副作用。示例仅展示核心机制，未在目标环境实际执行的测试不得宣称通过。
