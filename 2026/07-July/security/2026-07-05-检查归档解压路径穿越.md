# 检查归档解压路径穿越

ZIP 等归档文件中的路径可能包含父目录跳转或绝对路径。如果直接按归档中的文件名解压，可能覆盖目标目录之外的文件。解压前应规范化每个目标路径并确认它仍在允许目录内，同时限制文件数量和总解压大小。

## 实施步骤

1. 明确数据来源、目标范围和成功条件。
2. 在产生副作用前完成输入与权限检查。
3. 对失败、重试和恢复路径做独立验证。
4. 保存版本、命令和结果，避免把假设当作验证事实。

## 示例

```python
from pathlib import Path
root = Path('extract').resolve()
name = '../outside.txt'
target = (root / name).resolve()
if root not in target.parents:
    print('path traversal blocked')
```

## 验收与限制

至少覆盖正常路径、边界条件和失败路径。示例只展示核心机制，生产系统还需根据真实环境补充测试；未执行的测试不得宣称通过。
