# 评估模型生成摘要的忠实度

摘要流畅不代表忠实于原文。评估应检查关键事实、数字、否定关系和不确定性是否保留，并测量遗漏与新增内容。高影响摘要应保留原文链接或片段，让读者能够核对重要结论。

## 实施方法

明确输入契约、权限边界和成功条件；把错误分类、恢复策略和审计记录一并设计。对外部依赖记录版本和真实行为，不能仅凭接口文档推断所有边界条件。重要操作应先在可恢复环境验证，并保留失败时的停止机制。

## 示例

```python
def facts_preserved(required: set[str], summary: set[str]) -> bool:
    return required <= summary
assert facts_preserved({'date','amount'}, {'date','amount','context'})
```

## 验收清单

覆盖正常、边界和失败路径；确认没有秘密泄露，重复执行不会产生非预期副作用。示例仅展示核心机制，未在目标环境实际执行的测试不得宣称通过。
