# 为模型版本升级建立回归集

模型升级可能改变格式、事实性、拒答行为和工具调用方式。固定回归集应包含常见任务、边界案例和已知失败案例；对比新旧版本时记录模型标识、提示词、参数和检索索引，避免把配置变化误认为模型本身的影响。

## 实施步骤

1. 明确数据来源、目标范围和成功条件。
2. 在产生副作用前完成输入与权限检查。
3. 对失败、重试和恢复路径做独立验证。
4. 保存版本、命令和结果，避免把假设当作验证事实。

## 示例

```python
def same_setup(old: dict, new: dict) -> bool:
    return all(old.get(k) == new.get(k) for k in ('prompt_version','index_version','parameters'))
assert same_setup({'prompt_version':1,'index_version':2,'parameters':{}},{'prompt_version':1,'index_version':2,'parameters':{}})
```

## 验收与限制

至少覆盖正常路径、边界条件和失败路径。示例只展示核心机制，生产系统还需根据真实环境补充测试；未执行的测试不得宣称通过。
