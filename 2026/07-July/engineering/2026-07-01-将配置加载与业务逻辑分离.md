# 将配置加载与业务逻辑分离

把环境变量读取散布在业务函数中，会让测试依赖当前机器状态。应在应用入口加载配置、验证范围，再将明确的配置对象传给业务逻辑。这样更容易模拟不同配置，并让缺失配置在启动阶段失败，而不是在运行中途才暴露。

## 实施步骤

1. 明确数据来源、目标范围和成功条件。
2. 在产生副作用前完成输入与权限检查。
3. 对失败、重试和恢复路径做独立验证。
4. 保存版本、命令和结果，避免把假设当作验证事实。

## 示例

```python
def load_config(raw: dict) -> dict:
    if not raw.get('host') or not isinstance(raw.get('port'), int):
        raise ValueError('invalid configuration')
    return raw
assert load_config({'host':'localhost','port':8080})['port'] == 8080
```

## 验收与限制

至少覆盖正常路径、边界条件和失败路径。示例只展示核心机制，生产系统还需根据真实环境补充测试；未执行的测试不得宣称通过。
