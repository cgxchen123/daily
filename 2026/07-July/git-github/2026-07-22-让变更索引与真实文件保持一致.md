# 让变更索引与真实文件保持一致

索引容易因手工维护而遗漏文件或留下失效链接。可从实际文件树生成链接列表，并在提交前检查目标是否存在。生成逻辑应稳定排序，且要保留索引中的人工说明。

## 实施流程

1. 明确输入来源、目标范围和成功条件。
2. 在产生副作用前完成必要的校验与授权。
3. 为失败、恢复和复核保留可执行步骤。
4. 保存版本、运行命令、真实结果和未覆盖限制。

## 示例检查

```text
检查项：正常路径、边界条件、失败路径
记录项：版本、时间、结果、限制
发布前：确认目标状态与回滚方案
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认记录不含秘密，重复执行不会造成意外副作用。本文是实践指南，具体实现需结合项目实际环境验证，未执行的测试不得宣称通过。
