# 使用 deque 实现高效队列

在列表头部频繁插入或删除会移动大量元素，deque 为两端操作提供更合适的数据结构。选型仍应匹配访问模式：deque 不适合高效随机索引；如果需要优先级调度，应考虑堆或专用队列。

## 实施方法

明确输入契约、权限边界和成功条件；把错误分类、恢复策略和审计记录一并设计。对外部依赖记录版本和真实行为，不能仅凭接口文档推断所有边界条件。重要操作应先在可恢复环境验证，并保留失败时的停止机制。

## 示例

```python
from collections import deque
q = deque([1, 2])
q.append(3)
assert q.popleft() == 1
assert list(q) == [2, 3]
print('queue behavior checked')
```
