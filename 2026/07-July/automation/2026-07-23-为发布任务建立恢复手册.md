# 为发布任务建立恢复手册

恢复手册应说明如何判断当前状态、停止后续步骤、定位最近成功阶段、回滚变更和验证恢复结果。手册需要在正常时期演练，每个关键步骤应有负责人和成功判据。

## 实施流程

1. 明确输入来源、目标范围和成功条件。
2. 在产生副作用前完成必要的校验与授权。
3. 为失败、恢复和复核保留可执行步骤。
4. 保存版本、运行命令、真实结果和未覆盖限制。

## 示例检查

```text
检查项：正常路径、边界条件、失败路径
记录项：版本、时间、结果、限制
发布前：确认目标状态与回滚方案
```

## 验收清单

覆盖正常路径、边界条件和失败路径；确认记录不含秘密，重复执行不会造成意外副作用。本文是实践指南，具体实现需结合项目实际环境验证，未执行的测试不得宣称通过。
