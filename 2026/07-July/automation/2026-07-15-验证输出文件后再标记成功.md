# 验证输出文件后再标记成功

文件存在并不代表任务成功。发布前应检查大小、格式、必要字段、校验和以及与输入的对应关系；只有验证通过后才能写成功状态。若输出文件被覆盖，应保留可恢复副本或采用原子替换。

## 实施方法

明确输入契约、权限边界和成功条件；把错误分类、恢复策略和审计记录一并设计。对外部依赖记录版本和真实行为，不能仅凭接口文档推断所有边界条件。重要操作应先在可恢复环境验证，并保留失败时的停止机制。

## 示例

```python
from pathlib import Path
p = Path('_output.txt')
p.write_text('ok', encoding='utf-8')
assert p.stat().st_size > 0
p.unlink()
print('output checked')
```

## 验收清单

覆盖正常、边界和失败路径；确认没有秘密泄露，重复执行不会产生非预期副作用。示例仅展示核心机制，未在目标环境实际执行的测试不得宣称通过。
