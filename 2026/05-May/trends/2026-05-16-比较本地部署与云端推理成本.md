# 比较本地部署与云端推理成本

本地部署需要承担硬件采购、利用率、维护、升级和容量规划；云端推理则有调用费、网络延迟、数据治理和供应商依赖。应按真实吞吐、峰值、模型大小和服务等级估算总成本，而不是只比较单次调用价格。

## 实施建议

先定义业务契约、输入范围和失败时的行为。把正常路径、拒绝路径和恢复路径分别设计，并确保每次操作都有可观察结果。涉及外部服务或发布制品时，应记录版本、来源和验证证据；不要将未经执行的检查写成已通过。

## 示例

```python
def total_cost(unit_cost: float, calls: int, ops_cost: float) -> float:
    return unit_cost * calls + ops_cost
assert total_cost(0.01, 1000, 5) == 15
```

## 验收清单

覆盖正常输入、边界输入和失败路径；检查日志不含秘密、状态转换可追溯，重复执行不会造成意外副作用。示例只展示核心机制，生产环境需要专项测试。
