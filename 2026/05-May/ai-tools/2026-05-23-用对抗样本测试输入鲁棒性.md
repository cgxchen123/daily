# 用对抗样本测试输入鲁棒性

模型在普通样本上的表现不能代表它面对拼写错误、格式变化、提示注入和相互矛盾上下文时的表现。应建立可追踪的对抗测试集，记录失败类型，并在模型、提示词或检索配置变化后重新运行。

## 实施方法

先定义成功条件和失败时的行为，把事实、假设与待验证问题分开记录。对关键操作明确权限、输入边界和恢复方式，并为验证结果保留版本、命令和可复查证据。涉及敏感信息时遵循最小化原则，不要把秘密复制到日志或示例。

## 示例

```python
def redact(value: str, secret: str) -> str:
    return value.replace(secret, '[REDACTED]')
assert redact('token=abc', 'abc') == 'token=[REDACTED]'
```

## 验收清单

至少覆盖正常路径、边界路径和失败路径；说明示例未覆盖的限制。生产环境需根据真实并发、权限和依赖条件补充测试，未实际执行的测试不得宣称通过。
