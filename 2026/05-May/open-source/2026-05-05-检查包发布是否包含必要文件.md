# 检查包发布是否包含必要文件

本地仓库正常不代表发布包完整。发布前应检查构建出的 wheel、源代码包或其他制品，确认模块、许可证、资源文件和元数据都在其中，并在干净环境安装制品后运行最小测试。

## 落地流程

1. 明确目标、输入来源和成功条件。
2. 识别异常、权限、并发与恢复边界。
3. 在低风险环境验证，再将结果纳入发布检查。
4. 记录实际版本、命令、结果与未覆盖范围。

## 示例

```python
from zipfile import ZipFile
from pathlib import Path
# 对发布包列出内容，再检查许可证、模块和资源文件。
print('inspect built distribution before release')
```

## 验收与限制

示例只说明核心机制，不能替代项目专项测试。至少覆盖正常、边界和失败路径；未实际执行的测试不得标记为通过。涉及生产数据或不可逆操作时，应先备份并确认回滚方案。
