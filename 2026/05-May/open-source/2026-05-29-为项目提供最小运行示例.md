# 为项目提供最小运行示例

最小示例可以让使用者快速验证安装、基本 API 和预期输出。示例应独立、可复制，并注明依赖版本和运行命令；不要依赖未公开的本地文件、真实凭据或没有说明的服务端状态。

## 实施方法

先定义成功条件和失败时的行为，把事实、假设与待验证问题分开记录。对关键操作明确权限、输入边界和恢复方式，并为验证结果保留版本、命令和可复查证据。涉及敏感信息时遵循最小化原则，不要把秘密复制到日志或示例。

## 示例

```python
from dataclasses import dataclass
@dataclass(frozen=True)
class Example:
    command: str
    expected_output: str
assert Example('python demo.py', 'ok').command
```

## 验收清单

至少覆盖正常路径、边界路径和失败路径；说明示例未覆盖的限制。生产环境需根据真实并发、权限和依赖条件补充测试，未实际执行的测试不得宣称通过。
