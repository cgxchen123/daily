# 限制正则表达式的灾难性回溯

某些正则表达式在特定输入下会出现指数级回溯，造成 CPU 消耗飙升。不要把复杂正则直接用于任意长度的外部输入；应限制输入长度、使用更简单的模式，必要时采用具备超时或线性时间保证的解析工具。

## 落地流程

1. 明确目标、输入来源和成功条件。
2. 识别异常、权限、并发与恢复边界。
3. 在低风险环境验证，再将结果纳入发布检查。
4. 记录实际版本、命令、结果与未覆盖范围。

## 示例

```python
import re
pattern = re.compile(r'^[A-Za-z0-9_-]{1,32}$')
assert pattern.fullmatch('safe_name-1')
assert not pattern.fullmatch('x' * 1000)
print('bounded input checked')
```

## 验收与限制

示例只说明核心机制，不能替代项目专项测试。至少覆盖正常、边界和失败路径；未实际执行的测试不得标记为通过。涉及生产数据或不可逆操作时，应先备份并确认回滚方案。
