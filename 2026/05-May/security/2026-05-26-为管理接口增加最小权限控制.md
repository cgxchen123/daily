# 为管理接口增加最小权限控制

管理接口通常可以修改配置、查看敏感数据或触发高影响操作，应采用明确的角色和资源权限。不能只检查用户是否登录；每个请求都要验证操作者是否有权对指定对象执行该动作，并记录授权失败。

## 实施方法

先定义成功条件和失败时的行为，把事实、假设与待验证问题分开记录。对关键操作明确权限、输入边界和恢复方式，并为验证结果保留版本、命令和可复查证据。涉及敏感信息时遵循最小化原则，不要把秘密复制到日志或示例。

## 示例

```python
def can_access(role: str, action: str) -> bool:
    grants = {'admin': {'read', 'write'}, 'viewer': {'read'}}
    return action in grants.get(role, set())
assert can_access('viewer', 'read')
assert not can_access('viewer', 'write')
```

## 验收清单

至少覆盖正常路径、边界路径和失败路径；说明示例未覆盖的限制。生产环境需根据真实并发、权限和依赖条件补充测试，未实际执行的测试不得宣称通过。
