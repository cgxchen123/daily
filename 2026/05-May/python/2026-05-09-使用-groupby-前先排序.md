# 使用 groupby 前先排序

itertools.groupby 只会把相邻的相同键分成一组，并不会自动把所有相同键聚在一起。因此，若数据未按分组键排序，可能得到多个同名分组。应明确排序成本、键函数和内存需求；对于小型数据也可选择字典聚合。

## 实施建议

先定义业务契约、输入范围和失败时的行为。把正常路径、拒绝路径和恢复路径分别设计，并确保每次操作都有可观察结果。涉及外部服务或发布制品时，应记录版本、来源和验证证据；不要将未经执行的检查写成已通过。

## 示例

```python
from itertools import groupby
rows = sorted([("b", 1), ("a", 2), ("a", 3)])
groups = {k: [v for _, v in g] for k, g in groupby(rows, key=lambda x: x[0])}
assert groups["a"] == [2, 3]
print(groups)
```

## 验收清单

覆盖正常输入、边界输入和失败路径；检查日志不含秘密、状态转换可追溯，重复执行不会造成意外副作用。示例只展示核心机制，生产环境需要专项测试。
