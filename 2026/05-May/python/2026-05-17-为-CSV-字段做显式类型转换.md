# 为 CSV 字段做显式类型转换

CSV 读取结果通常是字符串，不能假设数字、日期或布尔值已经转换。转换时要定义空值、格式错误和范围校验策略；对大文件可逐行验证，避免一次性载入全部记录并在错误时丢失定位信息。

## 实施建议

先定义业务契约、输入范围和失败时的行为。把正常路径、拒绝路径和恢复路径分别设计，并确保每次操作都有可观察结果。涉及外部服务或发布制品时，应记录版本、来源和验证证据；不要将未经执行的检查写成已通过。

## 示例

```python
def parse_score(value: str) -> int:
    score = int(value)
    if not 0 <= score <= 100:
        raise ValueError('score out of range')
    return score
assert parse_score('88') == 88
```

## 验收清单

覆盖正常输入、边界输入和失败路径；检查日志不含秘密、状态转换可追溯，重复执行不会造成意外副作用。示例只展示核心机制，生产环境需要专项测试。
