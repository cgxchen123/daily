# 记录每次运行的版本与参数

自动化结果若没有关联代码版本、输入摘要和关键参数，出现回归时就很难复现。运行记录应足以解释“用什么版本处理了什么输入”，但不能泄露秘密。对于大型输入，可记录内容哈希而不是复制原始数据。

## 落地流程

1. 明确目标、输入来源和成功条件。
2. 识别异常、权限、并发与恢复边界。
3. 在低风险环境验证，再将结果纳入发布检查。
4. 记录实际版本、命令、结果与未覆盖范围。

## 示例

```python
from hashlib import sha256
payload = b'demo input'
record = {'version': 'abc123', 'input_sha256': sha256(payload).hexdigest()}
assert len(record['input_sha256']) == 64
print(record)
```

## 验收与限制

示例只说明核心机制，不能替代项目专项测试。至少覆盖正常、边界和失败路径；未实际执行的测试不得标记为通过。涉及生产数据或不可逆操作时，应先备份并确认回滚方案。
