# 为异步任务设置取消与清理

长时间运行的异步任务需要响应取消信号，并在退出时释放连接、临时文件和锁。取消可能发生在副作用执行中，因此应定义哪些阶段可安全中断，以及如何记录部分结果和恢复状态。

## 实施方法

先定义成功条件和失败时的行为，把事实、假设与待验证问题分开记录。对关键操作明确权限、输入边界和恢复方式，并为验证结果保留版本、命令和可复查证据。涉及敏感信息时遵循最小化原则，不要把秘密复制到日志或示例。

## 示例

```python
from pathlib import Path
from tempfile import TemporaryDirectory
with TemporaryDirectory() as tmp:
    state = Path(tmp) / 'state.txt'
    state.write_text('completed', encoding='utf-8')
    assert state.read_text(encoding='utf-8') == 'completed'
```

## 验收清单

至少覆盖正常路径、边界路径和失败路径；说明示例未覆盖的限制。生产环境需根据真实并发、权限和依赖条件补充测试，未实际执行的测试不得宣称通过。
