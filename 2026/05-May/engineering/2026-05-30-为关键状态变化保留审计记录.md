# 为关键状态变化保留审计记录

审计记录应覆盖操作者、对象、动作、时间、结果和关联请求 ID。日志需要防篡改、限制访问并设定保留期限；避免记录秘密或完整个人数据。审计系统自身也要监控写入失败，防止关键事件静默丢失。

## 实施方法

先定义成功条件和失败时的行为，把事实、假设与待验证问题分开记录。对关键操作明确权限、输入边界和恢复方式，并为验证结果保留版本、命令和可复查证据。涉及敏感信息时遵循最小化原则，不要把秘密复制到日志或示例。

## 示例

```python
def audit_record(actor: str, action: str, object_id: str, result: str) -> dict:
    return {'actor': actor, 'action': action, 'object_id': object_id, 'result': result}
assert audit_record('u1','read','r1','ok')['result'] == 'ok'
```

## 验收清单

至少覆盖正常路径、边界路径和失败路径；说明示例未覆盖的限制。生产环境需根据真实并发、权限和依赖条件补充测试，未实际执行的测试不得宣称通过。
