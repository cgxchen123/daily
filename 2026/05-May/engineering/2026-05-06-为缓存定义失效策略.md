# 为缓存定义失效策略

缓存能降低延迟和后端负载，但过期数据可能造成业务错误。设计缓存时应明确 TTL、主动失效、版本键和并发更新行为；对权限、余额等高敏感数据，不应为了性能而忽略一致性要求。

## 落地流程

1. 明确目标、输入来源和成功条件。
2. 识别异常、权限、并发与恢复边界。
3. 在低风险环境验证，再将结果纳入发布检查。
4. 记录实际版本、命令、结果与未覆盖范围。

## 示例

```python
def cache_key(user_id: str, version: str) -> str:
    if not user_id or not version:
        raise ValueError('missing cache-key component')
    return f'{version}:{user_id}'
assert cache_key('u1', 'v2') == 'v2:u1'
```

## 验收与限制

示例只说明核心机制，不能替代项目专项测试。至少覆盖正常、边界和失败路径；未实际执行的测试不得标记为通过。涉及生产数据或不可逆操作时，应先备份并确认回滚方案。
