# 为重置链接设置有效期

密码重置链接属于高敏感凭据，应使用足够随机的令牌、短有效期、一次性消费和安全存储。服务器应存储令牌摘要而非明文，成功重置后撤销相关会话，并避免把令牌写入日志或分析系统。

## 实施步骤

1. 明确输入来源、允许范围和失败行为。
2. 将校验与副作用分开，确保拒绝路径不会留下部分结果。
3. 为边界条件和故障恢复建立重复可执行的检查。
4. 保存版本、运行环境和真实输出，便于之后复查。

## 示例

```python
import hmac

def valid_signature(expected: str, received: str) -> bool:
    return hmac.compare_digest(expected, received)

if __name__ == "__main__":
    assert valid_signature("abc", "abc")
    assert not valid_signature("abc", "abd")
    print("signature comparison checked")
```

签名校验必须使用供应商规定的原始字节、算法和密钥；本例只演示常量时间比较，不负责生成签名或验证时间戳。

## 验收清单

覆盖正常场景、边界场景和失败场景；确认日志不含秘密，重复执行不会产生非预期副作用。本文示例不是生产级完整实现，未在目标环境实际执行的测试不得宣称通过。
