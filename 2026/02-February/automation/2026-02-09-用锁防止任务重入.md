# 用锁防止任务重入

任务可能因为调度器重试、执行时间超过周期或人工触发而重叠运行。锁机制需要定义获取失败时的行为、锁过期策略和崩溃清理方式。单机锁文件不能自动解决多主机并发，需要分布式协调。

## 推荐做法

先将目标写成可检查的条件，明确输入来源、失败方式和可恢复状态。把核心规则与外部 I/O 分开，避免同一段代码同时负责校验、执行、记录和补偿。涉及第三方服务时，应记录版本、时间和调用上下文，但不要记录密码、令牌或完整敏感数据。

## 最小示例与边界

```python
from pathlib import Path

lock = Path(".task.lock")
try:
    with lock.open("x", encoding="utf-8") as handle:
        handle.write("running\n")
    print("exclusive lock acquired")
finally:
    lock.unlink(missing_ok=True)
# Demo only: production code must handle stale locks and multi-host execution.
```

这是本地锁文件的演示，不解决多主机协调问题，也没有处理进程被强制终止后的陈旧锁。生产环境必须根据部署方式选用锁、租约或队列唯一键，并测试失败恢复。
