# 避免定时任务并发运行

同一任务被调度器重复触发时，两个实例可能同时处理相同输入，导致重复发布或文件冲突。单机脚本可用锁文件降低重入风险；多实例部署则应使用数据库锁、租约或任务队列的唯一键，并设计锁过期与崩溃恢复策略。

## 示例与验证

保存示例并在对应环境中执行；Git 命令应在目标仓库目录执行。

```python
from pathlib import Path

lock = Path("job.lock")
try:
    with lock.open("x", encoding="utf-8") as handle:
        handle.write("running\n")
    print("lock acquired")
finally:
    lock.unlink(missing_ok=True)

# 该示例只演示独占创建；生产实现还需处理陈旧锁与并发清理。
```

## 验收与限制

验证正常输入、边界输入和失败路径；确认没有意外副作用，并记录真实运行环境与输出。示例不等于生产级实现，涉及并发、权限、网络或真实数据时应增加针对性测试。未实际执行的检查不得标记为通过。
