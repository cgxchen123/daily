# 用生成器处理大型文本文件

一次性把大型文件读入列表会让内存随输入规模增长。生成器可以逐条产出记录，使处理过程保持有界内存；如果后续步骤需要重复遍历或随机访问，则应明确选择缓存或分块索引，而不是盲目使用生成器。

## 实施步骤

1. 明确输入来源、允许范围和失败行为。
2. 将校验与副作用分开，确保拒绝路径不会留下部分结果。
3. 为边界条件和故障恢复建立重复可执行的检查。
4. 保存版本、运行环境和真实输出，便于之后复查。

## 示例

```python
from pathlib import Path

def lines(path: Path):
    with path.open(encoding="utf-8") as handle:
        for line in handle:
            yield line.rstrip("\n")

if __name__ == "__main__":
    demo = Path("_demo.txt")
    try:
        demo.write_text("one\ntwo\n", encoding="utf-8")
        assert list(lines(demo)) == ["one", "two"]
        print("generator check passed")
    finally:
        demo.unlink(missing_ok=True)
```

示例逐行读取文本，不会把整个文件载入内存；如果消费者需要重复遍历，需重新打开文件或显式缓存结果。

## 验收清单

覆盖正常场景、边界场景和失败场景；确认日志不含秘密，重复执行不会产生非预期副作用。本文示例不是生产级完整实现，未在目标环境实际执行的测试不得宣称通过。
