# 用启动预检发现配置错误

把配置错误拖到处理请求时才暴露，会增加排查成本。服务启动阶段应验证必需配置、范围和依赖条件，并在失败时给出不包含秘密的错误信息。预检应快速且确定，避免启动时执行不可逆业务操作。

## 示例与验证

保存示例并在对应环境中执行；Git 命令应在目标仓库目录执行。

```python
def validate_config(config: dict) -> None:
    required = ("host", "port")
    missing = [key for key in required if not config.get(key)]
    if missing:
        raise ValueError("missing required config: " + ", ".join(missing))
    if not isinstance(config["port"], int) or not 1 <= config["port"] <= 65535:
        raise ValueError("port must be between 1 and 65535")

if __name__ == "__main__":
    validate_config({"host": "localhost", "port": 8080})
    print("config valid")
```

## 验收与限制

验证正常输入、边界输入和失败路径；确认没有意外副作用，并记录真实运行环境与输出。示例不等于生产级实现，涉及并发、权限、网络或真实数据时应增加针对性测试。未实际执行的检查不得标记为通过。
