# 数据类可变默认值陷阱

把列表或字典作为多个实例共享的默认值，会让一个对象的修改意外影响另一个对象。dataclasses 对可变默认值有专门限制，推荐使用 default_factory 明确创建独立对象。对于配置对象，还要考虑是否应该允许构造后修改。

## 示例与验证

保存示例并在对应环境中执行；Git 命令应在目标仓库目录执行。

```python
from dataclasses import dataclass, field

@dataclass
class Job:
    labels: list[str] = field(default_factory=list)

if __name__ == "__main__":
    first, second = Job(), Job()
    first.labels.append("urgent")
    assert second.labels == []
    print("instances are isolated")
```

## 验收与限制

验证正常输入、边界输入和失败路径；确认没有意外副作用，并记录真实运行环境与输出。示例不等于生产级实现，涉及并发、权限、网络或真实数据时应增加针对性测试。未实际执行的检查不得标记为通过。
