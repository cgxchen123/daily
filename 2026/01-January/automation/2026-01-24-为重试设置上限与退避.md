# 为重试设置上限与退避

无限重试会在依赖故障时放大流量，并让任务长期占用资源。重试策略应区分可重试错误与永久错误，设置最大次数、超时和退避上限；对非幂等操作，还必须先确认重复请求不会重复扣费或重复创建资源。

## 示例与验证

保存示例并在对应环境中执行；Git 命令应在目标仓库目录执行。

```python
import time

def retry(operation, attempts=3, base_delay=0.2):
    for index in range(attempts):
        try:
            return operation()
        except (TimeoutError, ConnectionError):
            if index == attempts - 1:
                raise
            time.sleep(min(base_delay * (2 ** index), 2.0))

if __name__ == "__main__":
    print(retry(lambda: "ok"))
```

## 验收与限制

验证正常输入、边界输入和失败路径；确认没有意外副作用，并记录真实运行环境与输出。示例不等于生产级实现，涉及并发、权限、网络或真实数据时应增加针对性测试。未实际执行的检查不得标记为通过。
