# 用一手证据判断技术趋势

热度、转发量和演示视频不能单独证明技术成熟。调研时优先查正式文档、版本发布记录、标准文本和可复现实验；记录测试条件、硬件、版本和限制。最后将证据、假设和待验证问题分开，避免把路线图描述成已经交付的能力。

## 示例与验证

保存示例并在对应环境中执行；Git 命令应在目标仓库目录执行。

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Evidence:
    claim: str
    source: str
    version: str
    reproduced: bool

if __name__ == "__main__":
    e = Evidence("supports feature X", "official release notes", "1.0", False)
    status = "verified locally" if e.reproduced else "not yet reproduced"
    print(status)
```

## 验收与限制

验证正常输入、边界输入和失败路径；确认没有意外副作用，并记录真实运行环境与输出。示例不等于生产级实现，涉及并发、权限、网络或真实数据时应增加针对性测试。未实际执行的检查不得标记为通过。
