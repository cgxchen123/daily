# 验证输入格式与语义

输入校验不能只看字符串长度或是否包含某个字符。应先定义合法格式、业务范围和拒绝策略，再在服务端验证；客户端校验仅用于改善交互。对于敏感操作，拒绝非法输入时还应确保没有产生部分副作用。

## 示例与验证

保存示例并在对应环境中执行；Git 命令应在目标仓库目录执行。

```python
def validate_quantity(value: object) -> int:
    if isinstance(value, bool) or not isinstance(value, int):
        raise ValueError("quantity must be an integer")
    if not 1 <= value <= 100:
        raise ValueError("quantity out of range")
    return value

if __name__ == "__main__":
    assert validate_quantity(2) == 2
    try:
        validate_quantity(0)
    except ValueError:
        print("out-of-range value rejected")
```

## 验收与限制

验证正常输入、边界输入和失败路径；确认没有意外副作用，并记录真实运行环境与输出。示例不等于生产级实现，涉及并发、权限、网络或真实数据时应增加针对性测试。未实际执行的检查不得标记为通过。
