# 限制上传文件扩展名

扩展名白名单是上传防护的一层，但它不能证明文件内容与声明一致。服务端应限制请求体大小、生成存储文件名、将文件放在非公开目录，并按需要检查内容特征。解析复杂格式时应考虑隔离执行与资源限制。

## 示例与验证

保存示例并在对应环境中执行；Git 命令应在目标仓库目录执行。

```python
ALLOWED_EXTENSIONS = {".txt", ".csv", ".png"}

from pathlib import Path

def check_extension(filename: str) -> str:
    suffix = Path(filename).suffix.lower()
    if suffix not in ALLOWED_EXTENSIONS:
        raise ValueError("file extension is not allowed")
    return suffix

if __name__ == "__main__":
    assert check_extension("data.CSV") == ".csv"
    print("extension accepted")
```

## 验收与限制

验证正常输入、边界输入和失败路径；确认没有意外副作用，并记录真实运行环境与输出。示例不等于生产级实现，涉及并发、权限、网络或真实数据时应增加针对性测试。未实际执行的检查不得标记为通过。
