# 为模型结构化输出加校验

要求模型返回 JSON 并不能保证字段齐全、类型正确或内容可信。应先解析格式，再用独立代码校验 schema、枚举值和业务范围；校验失败时可有限重试或转人工处理，不能把未验证的模型结果直接写入关键系统。

## 示例与验证

保存示例并在对应环境中执行；Git 命令应在目标仓库目录执行。

```python
import json

def parse_result(text: str) -> dict:
    value = json.loads(text)
    if not isinstance(value, dict):
        raise ValueError("expected object")
    if not isinstance(value.get("summary"), str):
        raise ValueError("summary must be a string")
    return value

if __name__ == "__main__":
    assert parse_result('{"summary":"ok"}') == {"summary": "ok"}
    print("schema check passed")
```

## 验收与限制

验证正常输入、边界输入和失败路径；确认没有意外副作用，并记录真实运行环境与输出。示例不等于生产级实现，涉及并发、权限、网络或真实数据时应增加针对性测试。未实际执行的检查不得标记为通过。
